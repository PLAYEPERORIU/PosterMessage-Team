## Reporting a Vulnerability

If you discover a potential security vulnerability, data leak, or exploit in any PosterMessage service:

1. **Do NOT open a public GitHub issue.** Public disclosure exposes users before a patch can be applied.
2. **Submit a confidential disclosure:**
   - Report the issue directly to the PosterMessage maintainers via our official communication channel at [postermessage.freebuff.app](https://postermessage.freebuff.app).
   - Alternatively, open a GitHub Security Advisory on our repository if enabled.
3. **Include details:**
   - Affected service URL / API endpoint.
   - Severity assessment (e.g. Critical, High, Medium, Low).
   - Step-by-step reproduction instructions or proof-of-concept payload.
   - Impact assessment on data confidentiality or server integrity.

---

## Response Timeline

- **Initial Response:** Within 24-48 hours of report submission.
- **Triage & Status Update:** Within 72 hours with an action plan.
- **Patch Deployment:** As quickly as possible depending on severity (critical issues prioritized immediately).
- **Public Disclosure:** Coordinated after the fix has been verified and deployed to production.

---

## Recognition

Security researchers who responsibly disclose verified vulnerabilities will be credited in our release notes and granted ecosystem VIP privileges.
